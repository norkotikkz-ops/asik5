## Description
A multi-page website that demonstrates the fundamentals of JavaScript: variables and operators, DOM manipulation, event handling, a calculator and a to-do list mini project. Pages are linked with a shared navigation bar.

## Pages and tasks
| Page | Tasks |
| --- | --- |
| `index.html` | Task 0 — first script (`console.log`, `alert`); Task 1 — variables & operators |
| `dom.html` | Task 2 — change text; Task 3 — change styles; Task 4 — add/remove list items |
| `events.html` | Task 5 — mouse events (`mouseover`/`mouseout`); Task 6 — keyboard events (`keyup`) |
| `calculator.html` | Task 7 — calculator (+, −, ×, ÷, division-by-zero check) |
| `todo.html` | Task 8 — to-do app (add, delete, mark completed; tasks kept in an array) |
